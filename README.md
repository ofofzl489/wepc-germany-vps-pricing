## “便宜”背后的两项成本

### 端口速率不等于可用速度

商家标的 200Mbps 是机房出口的端口速率，是理论上限。实际能跑多少，取决于机房到国内的国际链路拥不拥堵、回程绕不绕路。欧洲节点走普通国际线路，晚高峰路由绕美国或绕日本的情况很常见。

WePC 德国节点没有宣传回国优化，公开测评也明确说电信直连一般。所以 200Mbps 这个数字，实际使用时要按“国际线路共享带宽”去理解，晚高峰打个折扣是正常的。

### 流量双向计，超了限速不停机

1TB 流量是上传加下载一起算的，不是只算下行。做店铺后台、跑脚本、发视频这类用途，1TB 通常够；如果是持续推流或做文件中转，消耗会比想象中快。

有测评提到 WePC 部分套餐在超出流量后限速至 5Mbps，不停机也不额外扣费。这个处理方式比直接停机友好，但 5Mbps 基本只能维持基本连通，做业务会明显感觉到卡。

## 德国节点的延迟下限

欧洲到国内的物理距离摆在那，延迟普遍在 150–200ms 这个量级，这是光速决定的。任何德国节点都做不到香港节点那种 30–50ms 的体验。

这个数字意味着什么？SSH 敲命令会有轻微延迟感，网页后台操作没问题，实时性要求高的交互场景会难受。如果你的服务对象是国内用户、追求低延迟，WePC 自己也有香港节点可选，没必要在法兰克福上硬扛。
